更夫不做线上沙盒——一条 `docker compose up -d` 就能在本机跑起完整能力。还没部署的先看[快速上手](/quickstart)，然后按下面的路径把核心链路走一遍。

## 接入第一条告警

界面「Providers」→ 搜索 **Webhook** → 安装并复制 Webhook URL，用 curl 推一条模拟告警（完整命令见[快速上手](/quickstart)）。告警会实时出现在首页表格里，指纹、来源、严重度一目了然。

## 感受降噪与关联

连续推送几条同指纹、不同内容的告警，观察去重计数增长；用 CEL 过滤器与分面（Facets）按严重度、来源快速切片，体验告警风暴下的收敛。

## 值班与通知

- 安装钉钉 / 企业微信 / 飞书 Provider（原生支持加签、关键词、@手机号/邮箱）；
- 「值班管理」里建一个排班，工作流里用 `keep.oncall_phone(组名)` 让通知自动 @ 当前值班人；
- 给通知工作流挂上认领链接（`keep.oncall_ack_link`），值班人手机点开即可认领，MTTA 自动入统计。

## 事件与 AI 报告

把相关告警关联成事件，事件页点「报告」生成中文 AI 分析报告——在 Settings → AI Configuration 里配 DeepSeek / GLM / Qwen 等 OpenAI 兼容模型即可，无需海外 API。

## 工作流自动化

到「Workflows」页启用内置的 gengfu-* 模板（Prometheus→钉钉、Zabbix→企微、高危→飞书配色卡片），或照[工作流语法](/workflows/overview)写自己的自动化处置。
