## 更夫是什么？

更夫（Gengfu）是一个开源的告警聚合与 AI 事件管理平台：把分散在夜莺、Prometheus、Zabbix、云监控里的告警接入汇聚，做去重降噪与关联，按值班计划把对的通知发给对的人（钉钉 / 企业微信 / 飞书），沉淀为事件并生成中文 AI 分析报告，再通过声明式工作流完成自动化处置。

一句话定位：**监控交给夜莺们，告警之后的事交给更夫。**

## 定位与边界

监控采集不归更夫管——Zabbix、Prometheus、夜莺、云监控继续各司其职。更夫承接的是告警产生之后的一切：

```
监控层（夜莺 / Prometheus / Zabbix / 云监控 / 日志系统）
        │  webhook / API 接入
        ▼
更夫：接入汇聚 → 去重降噪关联 → 值班与通知（钉钉 / 企微 / 飞书）
        → 事件管理 → AI 分析与报告 → 工作流自动化处置
```

## 与 Keep 的关系

更夫基于开源项目 [Keep](https://github.com/keephq/keep)（MIT License）二次开发：Keep 提供了 400+ 集成、声明式工作流引擎与 AI 告警关联的地基能力；更夫在其上补齐国内生态的三块短板并独立演进——

- **国内 IM 触达**：钉钉（加签/关键词）、企业微信（@手机号）、飞书（签名/卡片）原生 provider，支持值班 @ 与免登录认领链接；
- **国产大模型**：OpenAI 兼容接口直连 DeepSeek / Qwen / GLM，AI 提示词与事件报告全中文输出；
- **内网私有化**：LDAP 认证、无 Redis 降级运行、出厂隐藏海外 SaaS 集成。
