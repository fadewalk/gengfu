# Keep 组级数据隔离改造方案

> 分支：`feature/group-isolation`
> 日期：2026-03-28

## 一、需求概述

在同一租户内，按组划分数据可见性：
- 每个组有自己独立的告警、Dashboard、Preset、Workflow
- 用户可属于**多个组**，看到所有所属组的资源
- 组内的高级配置只对组成员可见
- `group_id IS NULL` 表示"租户全局"资源（向后兼容）

## 二、核心架构

```
Tenant (硬隔离 — 现有)
  └── Group (软隔离 — 新增)
       ├── 资源有可选的 group_id
       ├── 用户可属于多个组
       └── 查询: tenant_id AND (group_id IN 用户组 OR group_id IS NULL)
```

**核心过滤逻辑：**
```python
def apply_group_filter(query, model, authenticated_entity):
    if not authenticated_entity.group_ids:
        return query.filter(model.group_id.is_(None))  # 只看全局资源
    return query.filter(
        or_(
            model.group_id.is_(None),           # 全局资源
            model.group_id.in_(group_ids),       # 组内资源
        )
    )
```

## 四、数据库模型设计

### Group 表

```sql
CREATE TABLE `group` (
    id VARCHAR(36) PRIMARY KEY,
    tenant_id VARCHAR(36) NOT NULL REFERENCES tenant(id),
    name VARCHAR(255) NOT NULL,
    description TEXT,
    created_by VARCHAR(255),
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(tenant_id, name)
);
```

### UserGroup 表

```sql
CREATE TABLE user_group (
    id VARCHAR(36) PRIMARY KEY,
    user_email VARCHAR(255) NOT NULL,
    group_id VARCHAR(36) NOT NULL REFERENCES `group`(id),
    role VARCHAR(50) DEFAULT 'member',  -- member, admin
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(user_email, group_id)
);
```

## 七、使用方式（集成到路由中）

在需要组过滤的路由中：

```python
from keep.api.core.group_filter import apply_group_filter, populate_group_ids

@router.get("/presets")
def get_presets(authenticated_entity = Depends(get_auth_verifier())):
    with Session(engine) as session:
        authenticated_entity = populate_group_ids(session, authenticated_entity)
        query = select(Preset).where(Preset.tenant_id == authenticated_entity.tenant_id)
        query = apply_group_filter(query, Preset, authenticated_entity)
        presets = session.exec(query).all()
        return presets
```
