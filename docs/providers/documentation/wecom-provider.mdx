## 接入步骤（企业微信群机器人）

1. 在企业微信中新建或打开一个群，进入「群设置 → 群机器人 → 添加」。
2. 创建完成后复制 Webhook URL 中 `key=` 之后的参数，填入 Provider 的 `key` 字段。
3. 如需限制来源，可在机器人设置中配置企业可信 IP 白名单。

## 工作流中使用

| 参数 | 说明 |
|---|---|
| `message` | 消息正文。无 @ 需求时支持企业微信 Markdown 子集（标题、加粗、引用、超链接、颜色文字） |
| `title` | 消息标题，非空时作为一级标题拼在正文前（仅 Markdown 消息生效） |
| `at_mobiles` | 需要 @ 的成员手机号列表，如 `["13800138000"]` |
| `at_all` | 是否 @ 所有人，默认 `false` |

```yaml
workflow:
  actions:
    - name: wecom-alert
      provider:
        type: wecom
        config: "{{ providers.wecom }}"
        with:
          message: |
            **{{ alert.name }}**
            严重度: <font color="warning">{{ alert.severity }}</font>
            环境: {{ alert.environment }}
          title: "告警: {{ alert.name }}"
```

:::note
企业微信的 @ 提醒只在纯文本（text）消息类型下生效。工作流中传入 `at_mobiles` 或 `at_all` 时，Provider 会自动降级为纯文本消息以保住 @ 能力。
:::

## 注意事项

- 机器人有频控限制（每分钟约 20 条），高频告警建议先经过更夫的降噪/聚合再通知。
- Markdown 不支持表格、图片与代码块，复杂排版请使用 text + 换行。
