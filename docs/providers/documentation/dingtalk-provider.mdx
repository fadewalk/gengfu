## 接入步骤（钉钉群机器人）

1. 在钉钉中新建或打开一个群，进入「群设置 → 机器人 → 添加机器人 → 自定义（通过 Webhook 接入自定义服务）」。
2. 安全设置三选一，本 Provider 支持「加签」与「自定义关键词」两种：
   - **加签**：选择「加签」，复制以 `SEC` 开头的密钥，填入 Provider 的 `secret` 字段（推荐）。
   - **自定义关键词**：选择「自定义关键词」，设置一个关键词（如「告警」），并保证发送的消息正文包含该关键词。
3. 完成后复制 Webhook URL 中 `access_token=` 之后的参数，填入 Provider 的 `access_token` 字段。

## 工作流中使用

| 参数 | 说明 |
|---|---|
| `message` | 消息正文，支持 Markdown |
| `title` | 消息标题（会话列表展示），默认「更夫告警」 |
| `at_mobiles` | 需要 @ 的手机号列表，如 `["13800138000"]` |
| `at_all` | 是否 @ 所有人，默认 `false` |

```yaml
workflow:
  actions:
    - name: dingtalk-alert
      provider:
        type: dingtalk
        config: "{{ providers.dingtalk }}"
        with:
          message: |
            #### 告警通知
            > {{ alert.name }}
            - 严重度: {{ alert.severity }}
            - 环境: {{ alert.environment }}
          title: "告警: {{ alert.name }}"
          at_mobiles: ["13800138000"]
```

## 注意事项

- 机器人有频控限制（每分钟约 20 条），高频告警建议先经过更夫的降噪/聚合再通知。
- 使用「自定义关键词」模式时，请确保 `message` 或 `title` 包含关键词，否则钉钉返回 `310000` 错误。
