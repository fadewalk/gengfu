## 接入步骤（飞书自定义机器人）

1. 在飞书中新建或打开一个群，进入「设置 → 群机器人 → 添加机器人 → 自定义机器人」。
2. 安全设置三选一，本 Provider 支持「签名校验」与「自定义关键词」两种：
   - **签名校验**：开启后复制密钥，填入 Provider 的 `secret` 字段（推荐）。
   - **自定义关键词**：设置一个关键词（如「告警」），并保证卡片标题或正文包含该关键词。
3. 复制 Webhook URL 中 `/bot/v2/hook/` 之后的路径段，填入 Provider 的 `hook_token` 字段。

## 工作流中使用

| 参数 | 说明 |
|---|---|
| `message` | 卡片正文，支持飞书卡片 Markdown 语法（加粗、链接、@ 人等） |
| `title` | 卡片标题，默认「更夫告警」 |
| `color` | 卡片头部分色：`red`/`orange`/`yellow`/`green`/`blue` 等，可按告警严重度映射 |
| `at_all` | 是否 @ 所有人，默认 `false` |

```yaml
workflow:
  actions:
    - name: feishu-alert
      provider:
        type: feishu
        config: "{{ providers.feishu }}"
        with:
          message: |
            **{{ alert.name }}**
            - 严重度: {{ alert.severity }}
            - 环境: {{ alert.environment }}
          title: "告警: {{ alert.name }}"
          color: "red"
```

:::note
自定义机器人场景下，@ 指定成员需要其飞书 user_id（开放平台接口获取），v1 仅支持 `at_all`。如需 @ 特定值班人，可在正文中使用手机号文本提醒。
:::

## 注意事项

- 机器人限流为每分钟 100 条（突发 5 条/秒），仍建议先降噪再通知。
- 未启用「签名校验」和「IP 白名单」时，任何拿到 Webhook URL 的人都能向群里发消息，生产环境建议开启签名。
